## Changes

- Onboarding: strengths, help, ten flat priorities and three Working on priorities, conditional faith, childhood interests, 15 quick picks, growth, people/places, routines, why and three optional baseline questions. Choices and written answers retain a device draft. No closing summary screen.
- Today: exact user-authored focus, one when/how question, silent tags; priority and where/how wheels; Easy → Normal → Stretch; three similar interests; occasional Learn mission with a matching exact book citation. One current focus per day.
- My map: why first, priorities, Want to try / From time to time / Into it / All in / On pause; a single mission card and fixed sheet controls. Interest sheets start with the next step of that interest rather than an unrelated priority. Stage moves require a tap; All in retains the two-interest limit.
- Future me: versioned One year out and Later in life pictures; Someday items with four horizons, open/lived/let-go states, normal ladders or substituted Someday starter missions, and an explicit link on the saved daily focus.
- Rhythms: only actual lived focuses are shown; grounded Sunday reflection, optional narrowing/similar interests/weekly priority, seasonal lookback, monthly baseline comparison in words and anniversary Someday refresh.
- Chloe: current master prompt and account-scoped Round 2 context, typed-focus tagging, night summaries/opener, explicit post-success interest-stage choices, and reserved rare interventions. These actions share the authenticated `chloe` Edge Function instead of creating a second public endpoint.

## Data and integrity

The migration preserves existing private missions and historical shared mission rows, retires the old shared catalogue from recommendations, and imports all 1,089 supplied missions, 44 links and 56 books. There were no exact text/size matches needing ID aliases against the 159 previous shared missions. Old interest states receive the specified one-time conversion. Obsolete category fields are removed from shared catalogues and active journey metadata.

New owner-scoped tables: places, someday_items, chloe_moments and checkin_summaries. Shared interest_links and learning_shelf are read-only to signed-in users. RLS is enabled on every new table. Daily focus replacement archives a completed focus and reflection, then replaces it in one transaction; failed or stale replacements preserve the original reflection. Moment reservations serialize competing tabs and enforce one per session and one per type per seven days.
